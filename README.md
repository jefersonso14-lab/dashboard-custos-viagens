# Dashboard Custos de Viagens

Reconstrução funcional do dashboard publicado em `dashboard-custos-viagens.jeferson-so14.chatgpt.site`, preparada para evolução e versionamento.

## Recursos da primeira versão
- Importação de XLSX, XLS, XLSB e CSV
- Consolidação de custos
- Pesquisa textual
- Filtro por categoria
- Indicadores de custo total, registros, média e categorias
- Gráfico de custos por categoria
- Tabela de detalhamento
- Exportação CSV
- Layout responsivo e minimalista

## Executar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

> Observação: como o código-fonte original do site publicado não estava disponível para exportação, esta é uma reconstrução funcional, não uma cópia byte-a-byte do projeto original.
